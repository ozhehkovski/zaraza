Бот запущен в локальном Docker Compose, вместе с PostgreSQL. Мониторинг включает 20 реальных товаров Zara Poland. Рабочая конфигурация: browser + page, обычный Chromium через Xvfb, две переиспользуемые страницы, без cookies.

## Повторная проверка перед подготовкой сервера

При более долгом запуске обнаружились ошибки DNS/соединений и таймауты. Их причина по логам не установлена; успешные запросы позднее восстановились. Также обнаружена ротация SKU в Zara: основной SKU размера меняется среди `twinnedSkus`, из-за чего одна подписка оставалась со старым состоянием. Код исправлен: учитываются только явные связи Zara; прежние внутренние ID, подписки и история сохраняются. Несвязанные SKU остаются неизвестными. Интеграционные тесты проверяют сохранение истории и отсутствие ложного restock при ротации.

После исправления все 20 подписок получили свежие состояния, `/health` стал `ok`. Backup восстановлен в отдельной БД с 20 подписками. Повторная нагрузка: 200 mock товаров, 2000 подписок, 200 запросов за цикл; baseline 346 ms, изменение 421 ms, общий прогон 3320 ms в Docker. Эти результаты не являются суточной проверкой или проверкой IP будущего сервера.
